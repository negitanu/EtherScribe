EtherScribe の初回安定版です。FortiGate / Palo Alto XML / Junos EX（ELS）の設定ファイルから HTML・Excel・JSON のパラメータシートを生成します。

配布物:

- **Windows x64**: `EtherScribe-1.0.0-win-x64.zip` を展開し `EtherScribe.exe` を起動してください。
- **Mac / Apple Silicon**: `EtherScribe-1.0.0-mac-arm64.dmg` を開き、アプリを Applications へコピーしてください。ZIP 版も用意しています。Intel Mac 用ではありません。
- `SHA256SUMS.txt`: ダウンロードしたファイルの SHA-256 を照合できます。

主な機能:

- 複数コンテキスト、アドレス・サービス・ポリシー・NAT・ネットワーク設定の帳票化と設定差分。
- Junos BGP の継承と AS 分離、静的ルート、LAG/VLAN/IRB の解析。
- Palo Alto DHCP サーバー／IPv4 リレー、shared/vsys の Syslog、メーカー別サービス表示。

入力設定と出力は利用者のローカルで処理します。実設定・個人の環境ファイル・資格情報・テスト設定は配布物に同梱していません。

この配布物には Windows Authenticode 署名と Apple notarization はありません。Mac 版は ad-hoc 署名です。OS が発行元の確認を求める場合があります。Mac では Finder からアプリを一度起動した後、システム設定の「プライバシーとセキュリティ」で開く操作が必要な場合があります。組織の端末ポリシーで実行が許可されない場合は管理者の方針に従ってください。

未対応: Cisco パーサー、PAN-OS set/Advanced Routing、Junos apply-groups 展開、実機への設定書き込み。Syslog のプロファイル定義は転送の実行・到達性を保証しません。
