## Why
ローカルの実設定を使って、合成 fixture だけでは見つからない解析漏れを確認し、パーサと検証能力を改善する。実設定そのものは Git・ログ・仕様へ取り込まない。
## What Changes
- `.data/` と `data/` をディレクトリ単位で Git 除外する。
- 実設定の内容・識別子を表示せず、構造と件数を用いて現行モデルの不足を検証する。
- 観測した構文に対応する合成 fixture を新規作成し、解析改善と回帰テストを追加する。
- ローカル実設定の検証を opt-in とし、通常テストは合成 fixture だけで完結させる。
## Capabilities
### Modified Capabilities
- `vendor-parsing`: 実設定で確認した構造への解析対応と欠落の検出。
- `repository-hygiene`: 実設定の非追跡とプライバシーを保つローカル検証。
## Impact
Go パーサ・モデル・回帰テスト・除外設定・検証手順。既存の未コミット変更を維持し、実設定の改変・コミット・push は行わない。
